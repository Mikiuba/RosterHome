# RosterHome CrewLink Bridge

Extensión local para Chrome. Hace que la importación de CrewLink se ejecute desde tu propio navegador y tu propia conexión, no desde Cloudflare.

## Instalar una vez

1. Conserva una copia descomprimida de este paquete en Windows.
2. Abre `chrome://extensions`.
3. Activa **Modo de desarrollador**.
4. Pulsa **Cargar descomprimida / Load unpacked**.
5. Selecciona la carpeta `chrome-extension`.
6. Abre `https://rosterhome.miguelesparciacastro.workers.dev/` y recarga.

Cuando RosterHome muestre **Bridge local detectado**, la importación directa está lista.

La contraseña de CrewLink se usa solo para automatizar la sesión en una pestaña local y no se envía a Cloudflare.
